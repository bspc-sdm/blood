# নতুন VPS-এর ভিত্তি তৈরি — এক বোতামে

এই কাজটা নতুন Contabo VPS-কে (IP `169.58.58.176`) প্রস্তুত করে: নিরাপত্তা (ফায়ারওয়াল, আপডেট), ডাটাবেস (PostgreSQL),
Redis, Java 21, ওয়েব সার্ভার (nginx) আর HTTPS সার্টিফিকেট, আর প্রতিদিনের ব্যাকআপ। এখনকার অ্যাপ (Vercel) যেমন চলছে তেমনই
চলবে — এতে কোনো বদল হয় না।

মোট সময়: ৫ মিনিট আপনার, ১০–২০ মিনিট GitHub-এর।

---

## ধাপ ১ — দুটো সিক্রেট যোগ করুন (একবারই)

1. কম্পিউটারের ব্রাউজারে **github.com** খুলে লগইন করুন।
2. **bspc-sdm/blood** রিপো খুলুন।
3. ওপরের **Settings** → বাঁ দিকে **Secrets and variables** → **Actions**।
4. সবুজ **New repository secret** বোতাম চাপুন।
5. প্রথম সিক্রেট:
   - **Name:** `VPS_HOST`
   - **Secret:** `169.58.58.176`
   - **Add secret** চাপুন।
6. আবার **New repository secret**, দ্বিতীয় সিক্রেট:
   - **Name:** `VPS_ROOT_PASSWORD`
   - **Secret:** Contabo-তে VPS কেনার সময় যে root পাসওয়ার্ড দিয়েছিলেন, হুবহু সেটাই।
   - **Add secret** চাপুন।

নাম দুটো হুবহু এভাবেই লিখবেন — বড় হাতের অক্ষর আর `_` সহ।

> ⚠️ **পাসওয়ার্ড কখনো চ্যাটে (Claude, WhatsApp, ইমেইল) পেস্ট করবেন না।** শুধু GitHub-এর ওই সিক্রেটের ঘরে।
> GitHub সিক্রেট কাউকে দেখায় না, লগেও লুকিয়ে রাখে।

> ⚠️ সেটআপ একবার সফল হলে `VPS_ROOT_PASSWORD` **মুছবেন না, বদলাবেন না** — GitHub এটা দিয়েই পরে VPS-এ ঢোকে।

## ধাপ ২ — চালান

1. রিপোর ওপরের **Actions** ট্যাব।
2. বাঁ দিকের তালিকায় **Setup VPS (base)**।
3. ডান দিকে **Run workflow** → যে ছোট বাক্স খোলে তাতে আবার সবুজ **Run workflow**।
4. কয়েক সেকেন্ড পর তালিকায় নতুন একটা লাইন আসবে (হলুদ ঘুরন্ত চিহ্ন)। সেটায় চাপলে কাজ দেখতে পাবেন।
   ১০–২০ মিনিট লাগতে পারে — পাতা বন্ধ করলেও কাজ চলতে থাকে।

## জেনে রাখুন

- সেটআপের পর VPS-এ **পাসওয়ার্ড দিয়ে SSH আর চলে না** — এটা নিরাপত্তার জন্য ইচ্ছা করে। জরুরি দরকারে Contabo প্যানেলের
  **VNC কনসোল** খোলা থাকে (সেখানে root পাসওয়ার্ড চলে)।
- **Uptime check** নামের আরেকটা কাজ প্রতি ১০ মিনিটে `https://169-58-58-176.sslip.io/healthz` দেখে; বন্ধ পেলে GitHub আপনাকে
  ইমেইল করে। সিক্রেট যোগ করার পর কিন্তু সেটআপ শেষ হওয়ার আগে এমন একটা ইমেইল এলে ভয়ের কিছু নেই।
- ডাটাবেস আর Redis-এর পাসওয়ার্ড VPS নিজে বানায়, শুধু VPS-এর ভেতরে থাকে — আপনাকে কিছু মনে রাখতে হবে না।
