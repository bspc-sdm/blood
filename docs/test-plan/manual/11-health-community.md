# ১১ — স্বাস্থ্য আলোচনা, টিপস, পেশাদার ব্যাজ, বাসায় সেবা

আগে: ফোন A = ডেমো রোগী রহিম; ফোন B = ডা. ডেমো হাসান (অনুমোদিত ব্যাজ); বাসায় সেবার জন্য ডেমো নার্স নাসরিন। ব্যাজের আবেদনের জন্য একটা আসল নতুন অ্যাকাউন্ট।
পথ: নিচের বারে "স্বাস্থ্য" › "আলোচনা" / "টিপস"।

## ক) প্রশ্নোত্তর

**M-HLT-01 · প্রশ্ন করা** — 🟠
- ধাপ: A: "প্রশ্ন করুন" → "আপনার প্রশ্ন" → "প্রশ্ন লিখুন" → "পোস্ট করুন"; আরেকটায় "আমার নাম দেখাবে না" টিক।
- ঠিক হলে: তালিকার ওপরে আসে; নাম লুকানোটায় অন্যরা "নাম প্রকাশে অনিচ্ছুক" দেখেন; খালি প্রশ্নে "প্রশ্ন লিখুন (১০০০ অক্ষরের মধ্যে)"; দিনে ৫টার বেশি আটকায়।
- ফল: ☐ পাস ☐ ফেল

**M-HLT-02 · ডাক্তারের উত্তর** — 🔴
- ধাপ: B: সেই প্রশ্ন → "উত্তর লিখুন" → "উত্তর দিন"।
- ঠিক হলে: উত্তরে B-র নাম আর ব্যাজ ("ডাক্তার"); A পুশ "আপনার প্রশ্নের উত্তর এসেছে", চাপলে সেই প্রশ্ন।
- ফল: ☐ পাস ☐ ফেল

**M-HLT-03 · ব্যাজ ছাড়া উত্তর দেওয়া যায় না** — 🔴
- ধাপ: A (সাধারণ ব্যবহারকারী) প্রশ্নে উত্তর দেওয়ার চেষ্টা।
- ঠিক হলে: উত্তরের ঘর নেই, বা "শুধু যাচাই করা স্বাস্থ্য পেশাজীবীরা উত্তর দিতে পারেন"।
- ফল: ☐ পাস ☐ ফেল

**M-HLT-04 · প্রশ্ন/উত্তর বদলানো ও মোছা** — 🟡
- ধাপ: A নিজের প্রশ্নে "বদলান" → সেভ → "মুছুন" → "প্রশ্নটা মুছবেন?"; B নিজের উত্তরে "বদলান"/"মুছুন" ("উত্তরটা মুছবেন?")।
- ঠিক হলে: বদলালে "সম্পাদিত"; মুছলে চলে যায়, উত্তরের সংখ্যা কমে; অন্যের প্রশ্নে "বদলান"/"মুছুন" নেই।
- ফল: ☐ পাস ☐ ফেল

**M-HLT-05 · রিপোর্ট** — 🟡
- ধাপ: একটা প্রশ্ন/উত্তরে "রিপোর্ট" → "রিপোর্ট করবেন?" → "রিপোর্ট করুন"।
- ঠিক হলে: অ্যাডমিন প্যানেল › রিপোর্ট-এ আসে; অ্যাডমিন মুছলে (M-ADM-15) চলে যায়, লেখক পুশ পান।
- ফল: ☐ পাস ☐ ফেল

**M-HLT-06 · অনেক প্রশ্ন — "আরও দেখুন"** — 🟢
- ঠিক হলে: ৩০টার পর "আরও দেখুন" দিয়ে পুরোনো আসে, একই প্রশ্ন দুবার নয়।
- ফল: ☐ পাস ☐ ফেল

## খ) টিপস

**M-HLT-07 · টিপস দেওয়া** — 🟠
- ধাপ: B: "টিপস" → "টিপস দিন" → "শিরোনাম", লেখা → পোস্ট।
- ঠিক হলে: "হেলথ টিপস"-এর ওপরে, ডাক্তার ব্যাজসহ; A (ব্যাজ নেই) "টিপস দিন" পান না বা "শুধু যাচাই করা স্বাস্থ্য পেশাজীবীরা টিপস দিতে পারেন"।
- ফল: ☐ পাস ☐ ফেল

**M-HLT-08 · টিপস বদলানো ও মোছা** — 🟢
- ধাপ: "টিপস বদলান"; "মুছুন" → "টিপসটা মুছবেন?"।
- ঠিক হলে: কাজ করে; ব্যাজ বাতিল হওয়া ডাক্তার বদলাতে পারেন না ("আপনার পেশাদার ব্যাজ এখন চালু নেই")।
- ফল: ☐ পাস ☐ ফেল

## গ) পেশাদার ব্যাজ

**M-HLT-09 · ব্যাজের আবেদন** — 🔴
- ধাপ: আসল নতুন অ্যাকাউন্ট: প্রোফাইল → "পেশাদার ব্যাজ" → "পেশা" (ডাক্তার) → নিবন্ধন নম্বর, "কর্মস্থল" → কাগজের ছবি (BMDC নিবন্ধন সনদ) → "আবেদন করুন"।
- ঠিক হলে: প্রোফাইলে "যাচাই চলছে"; "অ্যাডমিন যাচাই করার পর ব্যাজ দেখা যাবে।"; অ্যাডমিন প্যানেল › ব্যাজ-এ আসে।
- ফল: ☐ পাস ☐ ফেল

**M-HLT-10 · অনুমোদন / বাতিল** — 🔴
- ধাপ: অ্যাডমিন অনুমোদন দিন (M-ADM-05); আরেকটা আবেদনে কারণ লিখে বাতিল।
- ঠিক হলে: পুশ আসে; অনুমোদনে "আমার কাজ" › "আমার চেম্বার" খোলে, উত্তর/টিপস দেওয়া যায়; বাতিলে কারণ দেখা যায়, আবার আবেদন করা যায়।
- ফল: ☐ পাস ☐ ফেল

**M-HLT-11 · ব্যাজের তথ্য সংশোধন** — 🟡
- ধাপ: অনুমোদিত ডাক্তার: "পেশাদার ব্যাজ" › "তথ্য ঠিক করতে চাপুন" → "ব্যাজের তথ্য সংশোধন" → কর্মস্থল বদল → পাঠান।
- ঠিক হলে: " · সংশোধন যাচাই চলছে"; ব্যাজ চালু থাকে; অ্যাডমিন অনুমোদনে পুশ "আপনার ব্যাজের তথ্য সংশোধন হয়েছে"।
- ফল: ☐ পাস ☐ ফেল

## ঘ) বাসায় সেবা (নার্স/ডাক্তারের দিক আর রোগীর দিক)

**M-HLT-12 · বাসায় সেবা চালু (নার্স)** — 🟠
- ধাপ: নাসরিন: "আমার কাজ" › "আমার বাসায় সেবা" → "সেটিং বদলান" → "আমি রোগীর বাসায় গিয়ে সেবা দিই" → "কী কী সেবা দেন" (ইনজেকশন, স্যালাইন) →
  "আপনার লোকেশন থেকে কত দূর" ৫ কিমি → "কখন যেতে পারেন" → "রোগীরা যে নম্বরে ফোন করবেন" → ফি → "শর্তগুলো পড়ুন" → "সেভ করুন"।
- ঠিক হলে: রোগীর "বাসায় নার্স" তালিকায় আসে; "রোগীরা যেমন দেখবেন" ঠিক; নার্সের নিজের লোকেশন কাউকে দেখায় না, শুধু দূরত্ব। SMS যাচাই চালু থাকলে আগে "ফোন নম্বর যাচাই" → "কোড পাঠান" → "যাচাই করুন"।
- ফল: ☐ পাস ☐ ফেল

**M-HLT-13 · রোগী খোঁজেন ও ফোন করেন** — 🟠
- ধাপ: A: "অ্যাপয়েন্টমেন্ট" › "বাসায় সেবা" → "বাসায় নার্স" → "আমার কাছে" → "শুধু মহিলা", সেবা ফিল্টার → "ফোন করুন" → ১ ঘণ্টা পর "রেটিং দিন"।
- ঠিক হলে: দূরত্ব "প্রায় n কিমি দূরে" (≥২ কিমি দেখায়: "২ কিমির মধ্যে"); ৫ কিমির বাইরে থাকলে আসে না; রেটিং ৩০ দিনের মধ্যে, ১ ঘণ্টা পর; নার্সের পরিসংখ্যানে ফোনের সংখ্যা বাড়ে (কে ফোন করেছেন নয়)।
- ফল: ☐ পাস ☐ ফেল

**M-HLT-14 · অ্যাডমিন বাসায় সেবা বন্ধ করলে** — 🟡
- ধাপ: অ্যাডমিন রিপোর্টের পর বাসায় সেবা বন্ধ করেন।
- ঠিক হলে: তালিকা থেকে সরে; নার্স পুশ পান, আপিলের পথ পান।
- ফল: ☐ পাস ☐ ফেল
