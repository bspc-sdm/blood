# ০৮ — প্যাথলজি (ল্যাব)

আগে: ফোন C (বা ওয়েব) = ডেমো প্যাথলজির মালিক — "আমার কাজ" › "আমার প্যাথলজি" (ট্যাব "অনুরোধ" — ভাগ "নতুন", "নমুনা/চলছে", "রিপোর্ট দেওয়া"; ট্যাব "ল্যাব")।
ফোন A = ডেমো রোগী রহিম; ডাক্তার = ডা. ডেমো হাসান। দাম আর স্বাভাবিক মাত্রা বসানো শুধু ওয়েবে (`/work/lab/orders/prices`, `/work/lab/orders/ranges`)।

**M-LAB-01 · দাম বসানো (ওয়েব)** — 🔴
- ধাপ: ওয়েব › "পরীক্ষা ও দাম" → CBC ৪০০, Lipid profile ১২০০ (চালু), একটা নিজের নামের পরীক্ষা যোগ, সব পরীক্ষায় ছাড় ১০%, বাসা থেকে নমুনার ফি ২০০ → সেভ।
- ঠিক হলে: রোগী প্যাথলজির তালিকায় "সব পরীক্ষায় ১০% ছাড়", "বাসা থেকে নমুনা: ৳২০০", প্রেসক্রিপশন পাঠানোর সময় "আনুমানিক …" = (৪০০+১২০০)×০.৯ (+২০০ বাসা থেকে হলে)। **হাতে হিসাব মেলান।**
- ফল: ☐ পাস ☐ ফেল — হাতে হিসাব: ______

**M-LAB-02 · নতুন অনুরোধ আসা** — 🔴
- ধাপ: A পরীক্ষা পাঠান (M-RX-14)।
- ঠিক হলে: C পুশ "নতুন পরীক্ষার অনুরোধ"; চাপলে "অনুরোধ" › "নতুন"; রোগীর নাম, বয়স, পরীক্ষা, দামের ছবি — **রোগনির্ণয়/সমস্যা নয়**।
- ফল: ☐ পাস ☐ ফেল

**M-LAB-03 · কোড দিয়ে আসা রোগী (walk-in)** — 🟠
- ধাপ: "প্রেসক্রিপশন খুলুন" → রোগীর প্রেসক্রিপশনের কোড → খুলুন।
- ঠিক হলে: নতুন অনুরোধ তৈরি হয়; বাতিল প্রেসক্রিপশনে "এই প্রেসক্রিপশন বাতিল"।
- ফল: ☐ পাস ☐ ফেল

**M-LAB-04 · "নমুনা নিয়েছি"** — 🟠
- ঠিক হলে: অনুরোধ "নমুনা/চলছে"-তে; রোগী পুশ পান; রোগী দেখেন "নমুনা নেওয়া হয়েছে"।
- ফল: ☐ পাস ☐ ফেল

**M-LAB-05 · বাসা থেকে নমুনা — সময় নিশ্চিত** — 🔴
- আগে: A বাসা থেকে নমুনা চেয়েছেন (M-RX-15)।
- ধাপ: অনুরোধে বাসার ঠিকানা, ফোন, চাওয়া সময় দেখুন → "সময় নিশ্চিত করুন" → "দিন", "সময়", "রোগীর জন্য নোট (ঐচ্ছিক)" → "রোগীকে জানান"।
- ঠিক হলে: A পুশ "… আসবে"; A দেখেন "বাসা থেকে · …"। রোগী সময় বদলালে C পুশ পান।
- ফল: ☐ পাস ☐ ফেল

**M-LAB-06 · বাসায় যেতে পারব না** — 🟠
- ধাপ: "যেতে পারব না" → "বাসায় যেতে পারবেন না?" → "কারণ (ঐচ্ছিক)" → "যেতে পারব না"।
- ঠিক হলে: A পুশ "… বাসায় আসতে পারবে না — প্যাথলজিতে গিয়ে নমুনা দিন"; অনুরোধ থাকে; C আর বাসার ঠিকানা/ফোন **দেখে না**।
- ফল: ☐ পাস ☐ ফেল

**M-LAB-07 · রিপোর্ট দেওয়া** — 🔴
- ধাপ: "রিপোর্ট দিন" → প্রতিটা পরীক্ষার ছক ("পরীক্ষা", "ফলাফল", "একক", "স্বাভাবিক") পূরণ (একটা মান স্বাভাবিকের বাইরে দিন) → "আরেকটা সারি" → "রিপোর্টের ছবি ১" (ঐচ্ছিক) → "রিপোর্ট পাঠান"।
- ঠিক হলে: অনুরোধ "রিপোর্ট দেওয়া"; A পুশ পান; A-র রিপোর্টে মান, একক, স্বাভাবিক মাত্রা আর বেশি/কম চিহ্ন **হুবহু** (M-RX-16); ডাক্তার পুশ "একটা রিপোর্ট দেখার অপেক্ষায়" (ফি থাকলে টাকার পর)।
- ভুল: ফল খালি রেখে পাঠালে আটকায়।
- ফল: ☐ পাস ☐ ফেল

**M-LAB-08 · নিজের স্বাভাবিক মাত্রা (ওয়েব)** — 🟡
- ধাপ: ওয়েব › "স্বাভাবিক মাত্রা" → Hb পুরুষ/নারী আলাদা → সেভ → নতুন রিপোর্ট।
- ঠিক হলে: রিপোর্টের ছকে নতুন মাত্রা আগে থেকে বসে।
- ফল: ☐ পাস ☐ ফেল

**M-LAB-09 · অনুরোধ বাতিল ("করতে পারবে না")** — 🟡
- ঠিক হলে: A পুশ পান, অবস্থা "করতে পারবে না"; অন্য ল্যাবে পাঠানো যায়।
- ফল: ☐ পাস ☐ ফেল

**M-LAB-10 · রিপোর্টের ইতিহাস** — 🟡
- ধাপ: একই রোগীর দ্বিতীয় রিপোর্ট দিন।
- ঠিক হলে: রিপোর্টে "আগে: …" (আগের মান) দেখায় — ল্যাব শুধু নিজের দেওয়া আগের রিপোর্ট দেখে।
- ফল: ☐ পাস ☐ ফেল

**M-LAB-11 · ল্যাবের তথ্য বদলানো** — 🟠
- ধাপ: "ল্যাব" › "তথ্য বদলান" → ফোন/সময় বদলে সেভ; তারপর নাম বা লাইসেন্স বদলে সেভ।
- ঠিক হলে: ছোট বদলে তালিকায় সাথে সাথে; নাম/লাইসেন্স বদলালে আবার যাচাইয়ে যেতে পারে ("যাচাই চলছে") — অ্যাডমিনের তালিকায় আসে।
- ফল: ☐ পাস ☐ ফেল

**M-LAB-12 · প্যাথলজি মোছা** — 🟠
- ধাপ: "প্যাথলজি মুছে ফেলুন" → "প্যাথলজি মুছে ফেলবেন?" → নিশ্চিত।
- ঠিক হলে: তালিকা থেকে চলে যায়; আগের অর্ডার থেকে রোগীর বাসার ঠিকানা-ফোন মুছে যায়, রোগীর রিপোর্ট রোগীর কাছে থাকে। অ্যাডমিন বন্ধ করা ল্যাব মোছা যায় না ("বন্ধ করা প্যাথলজি সরানো যায় না")।
- ফল: ☐ পাস ☐ ফেল

- ঠিক হলে: অনুমোদিত ল্যাবই শুধু; "বাসা থেকে নমুনা নেয়" চিহ্ন; দাম M-LAB-01-এর সাথে মেলে।
- ফল: ☐ পাস ☐ ফেল
