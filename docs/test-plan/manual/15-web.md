# ১৫ — ওয়েব (lifolo.com): মোবাইল, ট্যাবলেট, কম্পিউটার

আগে: কম্পিউটারে Chrome; ফোনে Chrome আর (থাকলে) iPhone-এর Safari; একটা ট্যাবলেট বা ব্রাউজারের জানালা ছোট-বড় করে। ওয়েবে অ্যাপের একই অ্যাকাউন্ট।
ওয়েবে পুশ নোটিফিকেশন নেই (ঘণ্টার তালিকা আছে)। ওয়েবের ফিচারগুলো অ্যাপের মতো — নিচে শুধু ওয়েবের নিজের জিনিস আর প্রতিটা বড় পাতা একবার।
**অন্য সব ম্যানুয়াল ফাইলের অন্তত ২০% টেস্ট ওয়েবে চালান** (প্রতিটা রোলের মূল কাজ: রিকোয়েস্ট দেওয়া, বুকিং, প্রেসক্রিপশন লেখা, দোকানের অর্ডার, ল্যাবের রিপোর্ট, অ্যাম্বুলেন্স ডাকা)।

**M-WEB-01 · প্রথম খোলা ও এলাকা** — 🔴
- ধাপ: `https://lifolo.com` (নতুন/Incognito জানালা)।
- ঠিক হলে: এলাকা চায় বা হোম; অ্যাপের মতো চেহারা; ব্রাউজারের ট্যাবে নাম আর আইকন; `http://` দিলে `https://`-এ যায়; `www.lifolo.com` → `lifolo.com`।
- ফল: ☐ পাস ☐ ফেল

**M-WEB-02 · লগইন** — 🔴
- ধাপ: "লগইন" → ইমেইল → কোড → লগইন; তারপর ব্রাউজার বন্ধ করে খুলুন।
- ঠিক হলে: লগইন থাকে; `/login?next=/inbox` দিয়ে এলে লগইনের পর `/inbox`।
- ফল: ☐ পাস ☐ ফেল

**M-WEB-03 · পাতা রিফ্রেশ ও সরাসরি লিংক** — 🟠
- ধাপ: এই ঠিকানাগুলো সরাসরি খুলে F5: `/my-requests`, `/services/ambulance`, `/appointment`, `/health/discussion`, `/services/pharmacy/prescriptions`, `/prescriptions` (পুরোনো ঠিকানা — `/services/pharmacy/prescriptions`-এ চলে যাওয়ার কথা), `/work`, `/profile`, `/settings`, `/inbox`, `/help`, `/care`।
- ঠিক হলে: প্রতিটা খোলে (সাদা পাতা বা ৪০৪ নয়); লগইন লাগলে লগইনের পর সেখানেই ফেরে; ভুল ঠিকানায় (`/abc`) "পাওয়া যায়নি" পাতা।
- ফল: ☐ পাস ☐ ফেল

**M-WEB-04 · ব্রাউজারের Back/Forward** — 🟡
- ধাপ: হোম → একটা রিকোয়েস্ট → সেবা → অ্যাম্বুলেন্স → Back ×৩ → Forward।
- ঠিক হলে: ঠিক পাতাগুলোয় ফেরে, ডায়ালগ খোলা থাকলে Back-এ ডায়ালগ বন্ধ হয়।

- ঠিক হলে: কিছু পর্দার বাইরে যায় না; বড় পর্দায় তালিকা আর বিস্তারিত পাশাপাশি; পাশের মেনু ঠিক জায়গা দেখায়।
