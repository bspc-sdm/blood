- ঠিক হলে: "লেখা হয়েছে"; A-র প্রেসক্রিপশনে "কেনা n/m", যেটা নেই সেটা "ছিল না: …"; A পুশ পান "প্রেসক্রিপশনের ওষুধ দেওয়া হয়েছে" / "…-এ কিছু ওষুধ নেই"; অর্ডার "শেষ"-এ "দেওয়া হয়েছে";
  তারপর "বিক্রির হিসাবে তুলবেন?" → "হিসাবে তুলুন" দিলে বিক্রি খাতায় ওঠে, "এখন না" দিলে ওঠে না।
