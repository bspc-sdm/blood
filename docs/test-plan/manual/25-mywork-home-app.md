# ২৫ — "আমার কাজ" → "আজকের কাজ" (Android): অবস্থা, আজকের সংখ্যা, এখনই দেখুন, "সেবা দিন"

চিহ্ন: 🔴 Critical · 🟠 High · 🟡 Medium · 🟢 Low। ফোন B = সেবাদাতার ফোন (ডেমোর মালিকেরা চলবে; একাধিক ভূমিকার জন্য এমন অ্যাকাউন্ট যার চেম্বার + ফার্মেসি/ল্যাব আছে), ফোন C = সাধারণ রোগী (কোনো ব্যবসা নেই)।

কী নিয়ে (মালিকের অনুমোদন, ২৪ অক্টোবর ২০২৬): "আমার কাজ"-এর প্রথম পাতা এখন "আজকের কাজ" — উপরে ভূমিকার চিপ (একাধিক থাকলে), প্রতিটা ব্যবসার ঘরে খোলা / বিরতি / বন্ধ
আর আজকের ২–৪টা সংখ্যা (নতুনদের বেলায় "শুরু করতে যা বাকি"), তারপর "এখনই দেখুন", এক লাইনের "রোগীরা আপনাকে যেভাবে দেখেন", নিচে ব্যবসার কার্ড।
যাঁর কিছু নেই তাঁর একই ঘরে "সেবা দিন"। "আমার কাজ"-এর ভেতরের পাতাতেও (ফার্মেসি, ল্যাব, অ্যাম্বুলেন্স, ব্লাড ব্যাংক, আমার চেম্বার) একই নিচের বার।
শুরুর আগে: RC4 (এই বদলসহ), সার্ভারে work_today চালু। সময়: ≈ ৪৫ মিনিট।

**M-MWH-01 · ট্যাব লাফিয়ে আসে না** — 🔴
- ধাপ: ফোন B-তে অ্যাপ বন্ধ করে খুলুন (ধীর নেট হলে ভালো); নিচের বার দেখুন; সাথে সাথে "আমার কাজ" চাপুন।
- ঠিক হলে: পঞ্চম ঘর "আমার কাজ" শুরু থেকেই আছে (পরে এসে বার সরে না); তথ্য আসার আগে ধূসর কঙ্কাল, তারপর "আজকের কাজ"।

**M-MWH-02 · ভূমিকার চিপ আর মনে রাখা** — 🟠
- ধাপ: একাধিক ভূমিকার অ্যাকাউন্টে "সব · চেম্বার · ফার্মেসি · ল্যাব · ব্লাড ব্যাংক · অ্যাম্বুলেন্স" থেকে "ফার্মেসি" চাপুন; অন্য ট্যাবে গিয়ে ফিরুন; অ্যাপ বন্ধ করে খুলুন।
- ঠিক হলে: শুধু ফার্মেসির ঘর আর কাজ; ফিরে এলেও আর আবার খুললেও "ফার্মেসি" বাছা থাকে। একটাই ভূমিকা হলে চিপ নেই।
- ফল: ☐ পাস ☐ ফেল

**M-MWH-03 · খোলা / বিরতি / বন্ধ (ফার্মেসি, ল্যাব, চেম্বার)** — 🔴
- ধাপ: "বিরতি" → "৩০ মিনিট"; ফোন A-তে সেবা › ফার্মেসি দেখুন; ফোন B-তে "খোলা"; তারপর "বন্ধ"; চেম্বারেও একই (আজ বসেন এমন চেম্বার)।
- ঠিক হলে: বিরতিতে কমলা "বিরতি · আবার খুলবে …" (৩০ মিনিট পর নিজে খোলে); রোগীর তালিকায় "বন্ধ"; "খোলা" চাপলে সাথে সাথে খোলা; "বন্ধ" লাল।
  চেম্বারে "আজ সিরিয়াল চলছে" / "আজ বন্ধ"; বিরতিতে বুকিং বন্ধ হয় না। বাছা ঘরে ✓ আর রং — শুধু রং নয়। প্রতিটা বোতাম আঙুলে সহজে চাপা যায়।
- ফল: ☐ পাস ☐ ফেল

**M-MWH-04 · অ্যাম্বুলেন্স আর ব্লাড ব্যাংক** — 🟠
- ধাপ: অ্যাম্বুলেন্সের মালিক: প্রতিটা গাড়ির "খালি আছি / ট্রিপে আছি"; ব্লাড ব্যাংক: "স্টক দিন"।
- ঠিক হলে: অ্যাম্বুলেন্সে বিরতি নেই; গাড়ির পাতায় আবার আলাদা সুইচ লাগে না। ব্লাড ব্যাংকে "হালনাগাদ: … আগে" (৪৮ ঘণ্টার বেশি হলে লাল), "স্টক দিন" চাপলে মজুদের পাতা।
- ফল: ☐ পাস ☐ ফেল

**M-MWH-05 · আজকের সংখ্যা চাপলে সেই তালিকা** — 🔴
- ধাপ: ফার্মেসির "নতুন অর্ডার", "চলছে", "আজকের বিক্রি"; ল্যাবের "নতুন অনুরোধ", "রিপোর্ট বাকি"; চেম্বারের "আজকের সিরিয়াল"।
- ঠিক হলে: সংখ্যা বাংলা অঙ্কে (টাকা "৳১২,৩৪০"); চাপলে ঠিক সেই ভাগ খোলে ("আজকের বিক্রি" → বিক্রি, এক চাপে)। নতুন/অসম্পূর্ণ সেবাদাতার বেলায় সংখ্যার জায়গায়
  "শুরু করতে যা বাকি · …টার …টা হয়েছে" (ছবি, সময়, ঠিকানা …, ✓ দিয়ে), সব হয়ে গেলে লুকায়।
- ফল: ☐ পাস ☐ ফেল

**M-MWH-06 · এখনই দেখুন** — 🔴
- ধাপ: ফোন A থেকে একটা প্রেসক্রিপশন অর্ডার / ল্যাবের অনুরোধ / বুকিং পাঠান; ফোন B-তে "আজকের কাজ" নতুন করে খুলুন।
- ঠিক হলে: সবচেয়ে জরুরি আগে, সর্বোচ্চ ৫টা + "সব দেখুন (n)"; প্রতিটায় ভূমিকার ট্যাগ (সব-এ), এক লাইনের নাম, নিচে সময়/রোগী/কোড, একটাই বোতাম
  (গ্রহণ করুন / তৈরি / রিপোর্ট পাঠান / ডাকুন / উত্তর দিন / স্টক দিন) — চাপলে ঠিক জায়গায় যায়। কিছু না থাকলে এক লাইন "এখন কোনো কাজ বাকি নেই"।
- ফল: ☐ পাস ☐ ফেল

**M-MWH-07 · রোগীরা আপনাকে যেভাবে দেখেন — এক লাইন** — 🟡
- ধাপ: লাইনটা দেখুন, "দেখুন" চাপুন।
- ঠিক হলে: ছোট এক লাইন (নাম · মূল লাইন); "দেখুন" চাপলে রোগীদের তালিকার একই কার্ড (যাচাই চলা ব্যবসার নয়)।

**M-MWH-08 · ভেতরের পাতায় একই নিচের বার, উপরে পাতার নাম** — 🟠
- ধাপ: ঘরের মাথা ("খুলুন") চেপে ফার্মেসি/ল্যাব/অ্যাম্বুলেন্স/আমার চেম্বারে যান; নিচের বারে "হোম" চাপুন; আবার ঢুকে কোনো লেখার ঘরে টাইপ করুন।
- ঠিক হলে: সব পাতায় একই নিচের বার ("আমার কাজ" বাছা), উপরে পাতার নাম ("আমার ফার্মেসি" …); "হোম" চাপলে সোজা হোমে; কিবোর্ড খুললে বার লুকায়।

**M-MWH-09 · "সেবা দিন" (কোনো ব্যবসা নেই / অতিথি)** — 🔴
- ধাপ: ফোন C (লগইন করা, কিছু নেই) আর লগইন ছাড়া — নিচের পঞ্চম ঘর চাপুন; "ফার্মেসি › যোগ করুন"; "ডাক্তার ও স্বাস্থ্য বিশেষজ্ঞ › আবেদন করুন"।
- ঠিক হলে: ঘরের নাম "সেবা দিন"; কারা যোগ দিতে পারেন (ডাক্তার, ফার্মেসি, ল্যাব, ব্লাড ব্যাংক, অ্যাম্বুলেন্স); ফার্মেসি → যোগ করার ফর্ম (অতিথি হলে আগে লগইন);
  ডাক্তার → প্রোফাইলের "পেশাদার ব্যাজ"-এর আবেদন খোলে (যাচাই চলছে হলে "আপনার ব্যাজ যাচাই চলছে")।
