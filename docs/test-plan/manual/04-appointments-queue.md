# ০৪ — রোগীর অ্যাপয়েন্টমেন্ট আর সরাসরি সিরিয়াল

আগে: ফোন A = ডেমো রোগী রহিম; ফোন B = ডা. ডেমো হাসান (বা ওয়েবে `/work/pro`); সহকারীর জন্য ওয়েব/তৃতীয় ফোনে ডেমো সহকারী সুমন।
ডাক্তারের দিকের বিস্তারিত টেস্ট: [05-doctor-assistant.md](05-doctor-assistant.md)।

## ক) ডাক্তার খোঁজা ও বুকিং

**M-APT-01 · ডাক্তার খোঁজা ও ফিল্টার** — 🟠
- ধাপ: "অ্যাপয়েন্টমেন্ট" → "ডাক্তার" → "ফিল্টার": বিশেষজ্ঞতা ("বিশেষজ্ঞতা খুঁজুন" → "মেডিসিন"), "দিন", "হাসপাতাল / চেম্বার", "ফি", "নারী ডাক্তার", "এখন চেম্বারে" → "দেখান"; তারপর "সব মুছুন"।
- ঠিক হলে: প্রতিটা ফিল্টারে তালিকা মেলে (যেমন "এখন চেম্বারে" শুধু যাঁরা এই সময়ে বসেন); কিছু না মিললে "কোনো ডাক্তার পাওয়া যায়নি" + "সব ছাঁকনি সরান" / "সব জায়গায় খুঁজুন"।
- ফল: ☐ পাস ☐ ফেল

**M-APT-02 · ডাক্তারের বিস্তারিত** — 🟡
- ধাপ: একজন ডাক্তার খুলুন।
- ঠিক হলে: নাম, ডিগ্রি, বিশেষজ্ঞতা, চেম্বার (জায়গা, রুম, বার, সময়, ফি বা "ফি নেই"), "সিরিয়ালের জন্য ফোন" (থাকলে), "এই চেম্বারে অ্যাপয়েন্টমেন্ট" (চেম্বার অ্যাপে নিলে)।
- ফল: ☐ পাস ☐ ফেল

**M-APT-03 · অ্যাপয়েন্টমেন্ট চাওয়া (নিজের জন্য)** — 🔴
- ধাপ: "এই চেম্বারে অ্যাপয়েন্টমেন্ট" → "কার জন্য" = "আমি" → "তারিখ বেছে নিন" (চেম্বার যে বারে বসে) → "কী সমস্যা" → "অনুরোধ পাঠান"।
- ঠিক হলে: "অনুরোধ পাঠানো হয়েছে। নিশ্চিত হলে নোটিফিকেশন পাবেন।"; "আমার অ্যাপয়েন্টমেন্ট"-এ "অপেক্ষায়"; **ফোন B (ডাক্তার) পুশ পান**।
- ফল: ☐ পাস ☐ ফেল

**M-APT-04 · ভুল দিনে বুকিং** — 🟠
- ধাপ: চেম্বার বন্ধ এমন বার বাছুন; গতকাল; ৬০ দিনের বেশি পরে।
- ঠিক হলে: "সেদিন চেম্বার বন্ধ। চেম্বারের বারগুলোর একটা বেছে নিন।" / "আজ বা পরের কোনো তারিখ দিন" / আটকায়।
- ফল: ☐ পাস ☐ ফেল

**M-APT-05 · একই দিনে একই ডাক্তারে দুবার** — 🟡
- ধাপ: M-APT-03-এর পর একই দিনে আবার।
- ঠিক হলে: "সেদিন এই ডাক্তারের কাছে আপনার অনুরোধ আগে থেকেই আছে"।
- ফল: ☐ পাস ☐ ফেল

**M-APT-06 · পরিবারের সদস্যের জন্য** — 🟠
- আগে: A-র পরিবারে একজন সদস্য আছে (M-CAR-08)।
- ধাপ: বুকিংয়ে "কার জন্য" = সেই সদস্য।
- ঠিক হলে: ডাক্তারের তালিকায় সদস্যের নাম/বয়স; "আমার অ্যাপয়েন্টমেন্ট"-এ সদস্যের নামে।
- ফল: ☐ পাস ☐ ফেল

**M-APT-07 · নিশ্চিত হলে** — 🔴
- ধাপ: B (ডাক্তার) "নিশ্চিত করুন" (M-DOC-05)।
- ঠিক হলে: A পুশ পান; চাপলে "আমার অ্যাপয়েন্টমেন্ট"; অবস্থা "নিশ্চিত", "সিরিয়াল নং …", ডাক্তারের নোট (থাকলে); এখন ডাক্তারের/চেম্বারের ফোন দেখা যায়।
- ফল: ☐ পাস ☐ ফেল

**M-APT-08 · ডাক্তার "না করুন" দিলে** — 🟠
- ঠিক হলে: A পুশ পান; অবস্থা "নেওয়া হয়নি"।
- ফল: ☐ পাস ☐ ফেল

**M-APT-09 · রোগী বাতিল** — 🟠
- ধাপ: A: অ্যাপয়েন্টমেন্ট → "অ্যাপয়েন্টমেন্ট বাতিল" → নিশ্চিত।
- ঠিক হলে: B পুশ পান "অ্যাপয়েন্টমেন্ট বাতিল হয়েছে"; সিরিয়ালের তালিকা থেকে সরে।
- ফল: ☐ পাস ☐ ফেল

**M-APT-10 · সাড়া না এলে** — 🟡 (পরদিন)
- ধাপ: অনুরোধ পাঠিয়ে ডাক্তার কিছু করবেন না; ৪৮ ঘণ্টা পর/তারিখ পার হলে দেখুন।
- ঠিক হলে: অবস্থা "উত্তর আসেনি"; পুশ "অ্যাপয়েন্টমেন্টের অনুরোধে সাড়া আসেনি"।
- ফল: ☐ পাস ☐ ফেল

**M-APT-11 · আজকের অ্যাপয়েন্টমেন্টের মনে করানো** — 🟡
- ঠিক হলে: নিশ্চিত অ্যাপয়েন্টমেন্টের দিন সকাল ৯টার পর (ঢাকা) রোগী আর ডাক্তার মনে করানোর পুশ পান।
- ফল: ☐ পাস ☐ ফেল

## খ) সরাসরি সিরিয়াল (রোগীর দিক)

**M-APT-12 · সিরিয়াল শুরু হয়নি** — 🟠
- আগে: আজকের নিশ্চিত অ্যাপয়েন্টমেন্ট (সিরিয়াল ৩)।
- ঠিক হলে: অ্যাপয়েন্টমেন্টে "আজকের সিরিয়াল" — "এখনো শুরু হয়নি", "আপনার সিরিয়াল ৩"।
- ফল: ☐ পাস ☐ ফেল

**M-APT-13 · ডাক্তার শুরু করলে** — 🔴
- ধাপ: B: "আজকের সিরিয়াল" → "শুরু করুন" → "পরের রোগী" কয়েকবার।
- ঠিক হলে: A-তে (রিফ্রেশ বা নিজে থেকে) "এখন চলছে …", "আপনার আগে n জন", "আনুমানিক সময় …"; আগে ২ জন থাকলে পুশ "আপনার আগে ২ জন — চেম্বারে চলে আসুন"; নিজের পালায় "এখন আপনার পালা" / "এখনই চলে আসুন"।
- ফল: ☐ পাস ☐ ফেল

**M-APT-14 · বিরতি** — 🟡
- ধাপ: B "বিরতি" → পরে "আবার শুরু"।
- ঠিক হলে: A দেখেন "ডাক্তার একটু বিরতিতে"; আবার শুরুতে স্বাভাবিক।
- ফল: ☐ পাস ☐ ফেল

**M-APT-15 · "দেরি হবে"** — 🔴
- ধাপ: A: "দেরি হবে" → "২০ মিনিট" → "নোট (ঐচ্ছিক)": "জ্যামে আছি" → "পাঠান"।
- ঠিক হলে: "ডাক্তারকে পাঠানো হয়েছে"; A দেখেন "উত্তরের অপেক্ষায়", "সময় চেয়েছেন: ২০ মিনিট"; B পুশ পান। দিনে একবারই চাওয়া যায়।
- ফল: ☐ পাস ☐ ফেল

**M-APT-16 · ডাক্তার "ঠিক আছে"** — 🟠

- ঠিক হলে: A পুশ "ডাক্তার: ঠিক আছে, আপনার সিরিয়াল থাকছে"; সিরিয়াল একই।

**M-APT-17 · ডাক্তার "পরে আসুন"** — 🟠
- ঠিক হলে: A পুশ "ডাক্তার: পরে আসুন — আপনাকে সবার শেষে দেখা হবে"; A দেখেন "আপনাকে সবার শেষে দেখা হবে"; পেছনের রোগীরা এগিয়ে যান (২ জন আগে হলে তাঁদের পুশ)।
- ফল: ☐ পাস ☐ ফেল

**M-APT-18 · সিরিয়াল পার হয়ে গেলে** — 🟡
- ধাপ: B "পরের রোগী" দিয়ে A-র নম্বর পার করুন।
- ঠিক হলে: A দেখেন "আপনার সিরিয়াল পার হয়ে গেছে — চেম্বারে জানান"; শেষে "আজকের সিরিয়াল শেষ"।

**M-APT-19 · মাঝরাতের পর চলা সিরিয়াল** — 🟢
- ধাপ: রাত ১২টার পরেও (সকাল ৬টার আগে) গতকালের সিরিয়াল চালু রাখুন।
